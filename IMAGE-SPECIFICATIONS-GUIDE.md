## 3. Designer Checklist & Export Guidelines

### ✅ File Naming Conventions
* Use **lowercase letters with hyphens** only (e.g. `hero-elevation.jpg`, not `Hero Elevation Final (1).JPG`).
* Match exact filenames listed in this document so that developers or WordPress admins can replace files directly without breaking code references.

### ✅ Compression & Web Optimization
* Never deliver raw camera exports (e.g., 8 MB – 15 MB files).
* Export at **72 to 150 DPI** (DPI does not affect screen resolution, only pixel dimensions matter).
* Recommended tools for web compression: **TinyPNG**, **Squoosh.app**, or Photoshop *"Export for Web (Legacy)"* with quality set to 80–85%.

### ✅ Color Grading & Moodboard
* **Lighting**: Natural Pune daylight, warm sunrise/golden hour, or classy architectural twilight. Avoid harsh midday shadows or artificial oversaturated neon tones.
* **Greenery**: Vibrant, healthy botanical green (matching `#16A34A` / `#22C55E`) to highlight the blooming floral philosophy of Shivam Residency.
* **Materials**: Authentic granite finishes, wooden pergolas, glass balcony railings, and premium vitrified surfaces.
